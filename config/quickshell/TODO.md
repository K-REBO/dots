# Quickshell Widget 改善タスク

`TemplateWidget.qml` および関連コンポーネントの改善案です。

## 優先度：高 (実装のクリーン化)
- [ ] **mask の最適化**: 
  - `mask: Region { x: _widget.x; ... }` を `mask: Region { item: _widget }` に変更。
  - 理由: 手動のバインディングを減らし、Quickshell の推奨される書き方に合わせるため。
- [ ] **コンポーネントの統一**:
  - `TemplateWidget` 内のピル部分を `Pill.qml` を使った実装にリファクタリング。
  - 理由: 他のピル（Volume, Network 等）と見た目や挙動の整合性を取るため。

## 優先度：中 (ユーザー体験・堅牢性)
- [ ] **レイアウト依存の解消**:
  - `CalendarState.clockPillWidth` に依存している右マージン計算を、より抽象化されたレイアウト管理（または `Bar.qml` 側での配置制御）に移行。
  - 理由: カレンダーウィジェットが未ロードの場合に配置が崩れるリスクを避けるため。
- [ ] **ホバー遅延の導入**:
  - `HoverHandler` に短い遅延（`Timer`）を追加し、マウスがわずかに外れただけで閉じてしまう挙動を抑制。
- [ ] **アニメーションのブラッシュアップ**:
  - `Easing.OutCubic` から `Easing.OutQuart` または `Easing.OutExpo` への変更を検討。
  - 理由: モダンな Wayland シェル（Hyprland 等）により馴染む、より「速くて滑らかな」感触にするため。

## 優先度：低 (機能拡張)
- [ ] **アクセシビリティ**:
  - キーボードショートカットでの開閉および項目選択への対応。
